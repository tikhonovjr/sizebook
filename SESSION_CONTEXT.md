## ✅ ЗАФИКСИРОВАННЫЙ УСПЕХ: Farfetch (коммит aa1f9e4, 09.09.2026)
**Farfetch парсится полностью: title ✅, price ✅, image ✅.**
Ключевая находка: Firecrawl без `waitFor` отдаёт HTML **без `<head>`** (SPA не успевает
отрендериться) — ни og:title, ни JSON-LD, ни цена недоступны. Решение:
- `waitFor: 4000` в вызове Firecrawl `/v1/scrape` — даёт SPA время дорендериться
- Фолбэк title/image из `d.data.metadata` (собственные метаданные Firecrawl), когда
  HTML всё равно без head
- DOM-фолбэк цены по видимым `[class*="price"]`/`[data-testid*="price"]` элементам
  (добавлен и в Playwright-парсер, и в универсальный `parseProductFromHtml`)
- Цена очищается регексом от посторонних фраз типа "Import duties included"
**НЕ ТРОГАТЬ эту логику без крайней необходимости** — добивались долго, работает стабильно.

### ⚠️ ГЛАВНАЯ ПРОБЛЕМА СЕЙЧАС: скорость Ozon/WB
Клиент не будет ждать 20-30 секунд нажатия кнопки "Добавить". Корень проблемы —
и WB (цена), и Ozon (всё) блокируют по **гео-IP** (не датацентровый РФ-IP), а не
по антибот-фингерпринту — значит Playwright/Firecrawl принципиально не решают
это быстро, они просто дольше пытаются достучаться до заблокированного ресурса.

**Решение в работе:** РФ-прокси/сервер для fetch-запросов к WB/Ozon.
Нужен: 1) прокси-провайдер с РФ IP (резидентский или дата-центр в РФ),
2) переменная окружения в Railway (напр. `RU_PROXY_URL`), 3) код должен ходить
через прокси именно для доменов wildberries.ru/ozon.ru (fetch с proxy-agent),
не трогая остальные сайты.
